# روان‌نگار — نمونهٔ اولیهٔ PWA

## قابلیت‌های این نسخه
- رابط فارسی راست‌به‌چپ و فرم ۱۵‌بخشی
- انتخاب فایل صوتی و ضبط از میکروفون در مرورگرهای سازگار
- ویرایش متن مصاحبه و هر بخش
- ذخیرهٔ متنی فرم در حافظهٔ مرورگر
- خروجی TXT و JSON
- پوستهٔ آفلاین پس از اولین بارگذاری موفق و نصب Service Worker

## مواردی که هنوز پیاده‌سازی نشده‌اند
- تبدیل خودکار گفتار فارسی/ترکی آذربایجانی به متن
- ترجمهٔ خودکار ترکی به فارسی
- استخراج هوشمند اطلاعات و سؤال‌های تکمیلی
- نگهداری امن و رمزگذاری‌شدهٔ فایل صوتی
- ورود کاربران و پشتیبان‌گیری امن

این نمونهٔ اولیه برای آزمایش رابط کاربری است، نه استفاده با اطلاعات قابل‌شناسایی بیمار. localStorage رمزگذاری‌شده نیست. فایل ضبط‌شده در نسخهٔ فعلی به‌طور پایدار ذخیره نمی‌شود.

## اجرا روی گوشی
PWA برای نصب‌پذیری و Service Worker به HTTPS یا localhost نیاز دارد. می‌توان پوشه را روی یک میزبان استاتیک با HTTPS منتشر کرد؛ برای نمونه از GitHub Pages یا یک میزبانی استاتیک مشابه. پس از باز کردن نشانی در Chrome اندروید، منوی مرورگر را باز کن و گزینهٔ «Add to Home screen / افزودن به صفحهٔ اصلی» را بزن.

این پوسته پس از بارگذاری اولیه می‌تواند رابط را آفلاین باز کند، اما چون موتور هوش مصنوعی هنوز وصل نشده، پیاده‌سازی صوت/ترجمه/ساخت شرح حال خودکار انجام نمی‌شود. برای استفادهٔ بالینی، قبل از هرگونه ورود دادهٔ بیمار باید رمزگذاری، کنترل دسترسی، سیاست نگهداری داده و الزامات قانونی بررسی شوند.
